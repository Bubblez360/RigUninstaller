## RigUninstaller 1.0.0

The first public release. A Windows uninstaller that cleans up after itself, tells you what is risky to remove, and can undo what it did.

### Download and run

1. Download **`RigUninstaller-v1.0.0-win-x64.zip`** below (about 64 MB).
2. Unzip it to a normal folder, for example `C:\Tools\RigUninstaller`.
3. Double-click `RigUninstaller.exe` and answer **Yes** to the Windows permission prompt.

Nothing to install: the .NET runtime is inside the exe. Needs Windows 10 or 11, 64-bit.

> **"Windows protected your PC"?** The exe is not code-signed yet, so SmartScreen warns about every new unsigned program. Click **More info**, then **Run anyway**.

### What it does

- **Uninstalls properly**, one program or many at once, then finds the files, folders, shortcuts and registry keys the program left behind. Nothing is removed until you tick it.
- **Warns before you break something.** Drivers, runtimes, security software and hardware tools are tagged **Risky** or **Caution**, with the reason.
- **Undo center.** Registry keys are exported before they change, files go to the Recycle Bin, and restore points are offered.
- **Cleanup tab.** Temp files, Windows Temp, thumbnail, crash-dump, shader and browser caches; plus a scan for old folders that programs left in AppData, ProgramData and Program Files.
- **Also:** broken-entry clean-up, drive and disk-usage views, Microsoft Store apps, startup manager (with "Add app"), winget check, Find-by-window, light and dark theme.

See the [README](https://github.com/Bubblez360/RigUninstaller#readme) for a tour and the safety rules.

### Good to know

- This is a tool that deletes things, so it asks before every removal. Read the confirmation dialogs.
- Cache cleaning is the one place files are deleted for good instead of going to the Recycle Bin (after a confirmation).
- Logs, backups and settings are kept in a `Data` folder next to the exe. Keep that folder when you update.
