## RigUninstaller 1.0.1

A small update: the program-finding button that did not work is replaced by two that do.

### What changed

- **New: Quick filter.** One click shows a ready-made view of your program list: installed in the last 30 days, not used for 6+ months, 500 MB or more, risky to remove, broken entries, or on your bloatware list. It works together with the search box, shows in the status bar, and only changes what the list shows. Nothing is removed by it.
- **New: Open windows.** Lists the windows open right now, one per program. Pick one and its program is selected in the list. No aiming needed.
- **Removed: Find by window.** The crosshair you had to drag onto a window kept landing on the wrong program (often Explorer), so it is gone. Open windows does the same job.

### Download and run

1. Download **`RigUninstaller-v1.0.1-win-x64.zip`** below (about 64 MB).
2. Unzip it to a normal folder, for example `C:\Tools\RigUninstaller`.
3. Double-click `RigUninstaller.exe` and answer **Yes** to the Windows permission prompt.

Nothing to install: the .NET runtime is inside the exe. Needs Windows 10 or 11, 64-bit.

**Updating from 1.0.0:** unzip the new version into a new folder and copy your old `Data` folder across (it holds your logs, backups, Keep tags and settings).

> **"Windows protected your PC"?** The exe is not code-signed yet, so SmartScreen warns about every new unsigned program. Click **More info**, then **Run anyway**.
